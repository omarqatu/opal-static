# Opal Galaxy — static preview (v0.7)

Static preview of the Opal Galaxy Air Condition Trading L.L.C website, for content and design approval by the client before the dynamic build.

| File | What it is |
|---|---|
| `index.html` | The full site in one page (EN default, AR toggle). Product and brand pages open by hash: `#window`, `#carrier`, `#maintenance` … |
| `brand-guide.html` | Brand identity guide (logo, colours, type) — Arabic |
| `logo/` | Mark v1 (SVG) — standard and reversed for navy backgrounds |
| `status.md` | Project status, decisions and open items |

**Preview only.** Pages carry `noindex` and `robots.txt` blocks crawlers. Some content (delivery times, service commitments) is awaiting the client's confirmation and must not be indexed.
